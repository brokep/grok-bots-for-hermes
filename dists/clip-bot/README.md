# Clip Bot (Hermes profile distribution)

Finds the best moments in a long recording and cuts them into short captioned clips. Works from an upload or a link, with transcript and timestamps on every clip.

Install: `hermes profile install ./dists/clip-bot --alias -y` (from the repo root) then `grok-clip-bot chat`.

Skills: 6  Routines: 2  Integrations: slack, notion-workspace, linear, figma
