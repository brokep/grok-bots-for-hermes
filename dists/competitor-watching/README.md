# Competitor Watch (Hermes profile distribution)

Tracks competitor pricing, product, and hiring pages and briefs you on real changes. Starts from a list of URLs you paste.

Install: `hermes profile install ./dists/competitor-watching --alias -y` (from the repo root)  then `grok-competitor-watching chat`.

Skills: 5  Routines: 2  Integrations: slack, notion-workspace, linear
