# Product Support Inbox Assistant (Hermes profile distribution)

Helps you find and draft answers to product questions. Never sends emails without you.

Install: `hermes profile install ./dists/customer-question-drafter --alias -y` (from the repo root)  then `grok-customer-question-drafter chat`.
