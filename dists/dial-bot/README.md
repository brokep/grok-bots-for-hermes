# dial bot (Hermes profile distribution)

Places outbound Bland AI phone calls when you ask, then reports what happened. On first use it asks for a Bland API key and voice.

Install: `hermes profile install ./dists/dial-bot --alias -y` (from the repo root) then `grok-dial-bot chat`.
