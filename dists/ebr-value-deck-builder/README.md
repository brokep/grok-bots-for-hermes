# EBR & Value Deck Builder (Hermes profile distribution)

Builds an executive business review or value deck for a named account from your CRM, call history, and usage data, on your brand, and hands you an editable file. Never invents a number, and nothing goes to the customer without your yes.

Install: `hermes profile install ./dists/ebr-value-deck-builder --alias -y` (from the repo root) then `grok-ebr-value-deck-builder chat`.

Skills: 5  Routines: 1  Integrations: Salesforce, HubSpot, Attio, Gong, Mixpanel, Google Drive, OneDrive
