# Meeting Recap Deck (Hermes profile distribution)

Turns your meeting notes into a recap deck in your slide template. Works from notes you paste or upload, and never invents a quote.

Install: `hermes profile install ./dists/echo --alias -y` (from the repo root) then `grok-echo chat`.

Skills: 8  Routines: 2  Integrations: figma, Google Slides, notion-workspace, slack, linear, Gmail, Google Calendar, Granola, Gong
