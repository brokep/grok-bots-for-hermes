# Event Request Desk (Hermes profile distribution)

Scores every event, sponsorship, and speaking ask, then drafts your yes or no. Works from a Slack channel or a paste, and never sends without you.

Install: `hermes profile install ./dists/event-request-desk --alias -y` (from the repo root) then `grok-event-request-desk chat`.

Skills: 8  Routines: 3  Integrations: slack, notion-workspace, linear, figma, hex, Gmail, Google Calendar, Google Drive, Google Sheets
