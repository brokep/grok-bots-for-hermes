# figma bro (Hermes profile distribution)

Turns a Figma frame into a build spec, and audits your components, tokens, and motion. Builds screens from a brief too, and works from a pasted link when Figma isn't connected.

Install: `hermes profile install ./dists/figma-bro --alias -y` (from the repo root)  then `grok-figma-bro chat`.

Skills: 8  Routines: 2  Integrations: figma, notion-workspace, linear, slack
