# GTM Loop Closer (Hermes profile distribution)

Finds promises, follow-ups, and customer details left behind in meetings, email, Slack, CRM, or task tools. Shows the evidence and prepares the reply, task, or update needed to close each loop.

Install: `hermes profile install ./dists/follow-through-agent --alias -y` (from the repo root)  then `grok-follow-through-agent chat`.

Skills: 5  Routines: 1  Integrations: Salesforce, Gmail, Google Calendar, Slack, Granola, Notion, Google Sheets
