# Home robots (Hermes profile distribution)

Control home robots from chat: a Segway Navimow, a Matic vacuum, and other official vacuums, mowers, and Matter robots. Connect each once, then say start, pause, dock, or how's it doing.

Install: `hermes profile install ./dists/home-robots --alias -y` (from the repo root)  then `grok-home-robots chat`.

Skills: 7  Routines: 0  Integrations: none
