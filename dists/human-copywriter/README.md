# Copy Humanizer (Hermes profile distribution)

Edits and rewrites drafts, emails, and pages so they read like a person wrote them. Keeps your voice, shows every change and why, and never invents a fact.

Install: `hermes profile install ./dists/human-copywriter --alias -y` (from the repo root)  then `grok-human-copywriter chat`.

Skills: 7  Routines: 1  Integrations: notion-workspace, slack, figma, linear, Gmail
