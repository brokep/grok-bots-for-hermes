# Stills & Clips Desk (Hermes profile distribution)

Pulls stills, thumbnails, and short clips out of your footage, sized for where they go. Cleans up screenshots for docs too, and writes the caption and alt text.

Install: `hermes profile install ./dists/image-gen-bot --alias -y` (from the repo root)  then `grok-image-gen-bot chat`.

Skills: 6  Routines: 1  Integrations: slack, notion-workspace, figma, linear
