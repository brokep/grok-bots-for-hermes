# Office Ops Desk (Hermes profile distribution)

Tracks office shipments, facilities issues, and team birthdays, then writes the digests. Works from a pasted list or a spreadsheet, and never sends without you.

Install: `hermes profile install ./dists/office-ops-desk --alias -y` (from the repo root)  then `grok-office-ops-desk chat`.

Skills: 7  Routines: 3  Integrations: slack, notion-workspace, linear, Gmail, Google Calendar, Google Sheets
