# Outbound Prospecting (Hermes profile distribution)

Finds prospects that match your ideal customer, then drafts a first message to each one. Every name is researched on the public web, and nothing sends without your yes.

Install: `hermes profile install ./dists/pg --alias -y` (from the repo root)  then `grok-pg chat`.

Skills: 8  Routines: 3  Integrations: slack, notion-workspace, linear, Gmail, Google Sheets, X, Salesforce
