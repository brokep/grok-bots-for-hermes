# Pipeline Pulse (Hermes profile distribution)

Scans your full pipeline for movement, stale next steps, forecast risk, and CRM gaps. Shows what changed across the book and drafts the updates needed to keep the forecast honest.

Install: `hermes profile install ./dists/pipeline-health-and-forecast --alias -y` (from the repo root)  then `grok-pipeline-health-and-forecast chat`.

Skills: 3  Routines: 1  Integrations: Salesforce, Gmail, Slack, Granola, Notion, Google Sheets
