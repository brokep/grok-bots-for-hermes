# Pitch Deck Coach (Hermes profile distribution)

Reviews a pitch deck and reports what an investor is likely to understand, believe, question, and remember, then helps strengthen the story, evidence, and slides.

Install: `hermes profile install ./dists/pitch-deck-coach --alias -y` (from the repo root) then `grok-pitch-deck-coach chat`.
