# Product Idea Stress Test (Hermes profile distribution)

Investigates a product or startup idea for founders. Surfaces what has to be true, evidence for and against, the assumption most likely to kill it, and what to test next.

Install: `hermes profile install ./dists/product-idea-stress-test --alias -y` (from the repo root)  then `grok-product-idea-stress-test chat`.
