# Projects Manager (Hermes profile distribution)

Runs your team's projects from Notion: one row per project, a channel per project, and tasks your specialist bots claim. You decide, agents execute, and it never does the specialist work itself.

Install: `hermes profile install ./dists/projects-manager --alias -y` (from the repo root)  then `grok-projects-manager chat`.

Skills: 1  Routines: 0  Integrations: Notion, Slack
