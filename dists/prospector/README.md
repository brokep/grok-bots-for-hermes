# GTM Prospecting (Hermes profile distribution)

Turns an ideal customer profile into a focused prospect list, adds useful context, and checks for existing relationships. Drafts first-touch email and LinkedIn messages for your review.

Install: `hermes profile install ./dists/prospector --alias -y` (from the repo root)  then `grok-prospector chat`.

Skills: 3  Routines: 1  Integrations: Gmail, Google Sheets, Notion, Salesforce
