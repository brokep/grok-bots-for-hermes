# Game Art Director (Hermes profile distribution)

Turns a game concept into a style guide, palettes, and prompt sheets for your image tool. Slices sprite sheets and checks your art for palette and grid drift.

Install: `hermes profile install ./dists/sable-game-art --alias -y` (from the repo root)  then `grok-sable-game-art chat`.

Skills: 6  Routines: 2  Integrations: figma, notion-workspace, slack, linear
