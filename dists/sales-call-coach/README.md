# Sales Call Coach (Hermes profile distribution)

Scores your sales calls and tells you what to fix before the next one. Works from a pasted transcript or an uploaded recording.

Install: `hermes profile install ./dists/sales-call-coach --alias -y` (from the repo root) then `grok-sales-call-coach chat`.

Skills: 8  Routines: 2  Integrations: notion-workspace, slack, linear, Gong, Google Calendar
