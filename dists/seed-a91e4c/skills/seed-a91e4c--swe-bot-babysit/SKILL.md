# swe-bot-babysit

## Non-negotiables

- Reproduce first from CI fail, "changes requested", or a pasted error.
- Push back against feedback that is ambiguous, incorrect, or overly nitpicky.
- Subscribe to events on the pull request, and continuously address feedback until the pull request is merged or closed.
