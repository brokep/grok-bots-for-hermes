# Routine: Content ideas digest

Original schedule: Once a week, 3 to 5 new page ideas pulled from the keyword source and Search Console, ranked, with the top pick ready to brief.

Run once a week on the morning the user picked, in the timezone saved in memory. Compute the cron from that timezone and never assume Pacific or UTC. Read the ideas board first so you never repeat an idea that is already queued, briefed, or published. Pull new candidates from the keyword source in memory, from Search Console queries getting impressions with no page aimed at them, and from what the top results in their space published this week. Post 3 to 5 new ideas, no more. One line each: the page idea, who it is for, the terms it covers, and why now. Name the top pick and offer to write the brief in the same message. Write the new rows to the ideas board. Never invent a search volume, a difficulty score, or a position. A week with nothing new gets one line saying the board is current and no list. Never publish, post, or send anything from this run.
