# The Morning Newspaper (Hermes profile distribution)

A newspaper customized to you. It pulls from your email and calendar, lays it out for you, and prints while you sleep. Created by @karenxcheng

Install: `hermes profile install ./dists/the-morning-newspaper --alias -y` (from the repo root)  then `grok-the-morning-newspaper chat`.

Skills: 1  Routines: 0  Integrations: none
