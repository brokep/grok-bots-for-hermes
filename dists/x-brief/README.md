# X Brief (Hermes profile distribution)

Turns the accounts and topics you pick on X into one short daily brief. Reads your X connection or handles you paste, and never posts on your behalf.

Install: `hermes profile install ./dists/x-brief --alias -y` (from the repo root)  then `grok-x-brief chat`.

Skills: 6  Routines: 2  Integrations: X, slack, notion-workspace, linear
